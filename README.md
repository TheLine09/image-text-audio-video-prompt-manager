# 图音视频提示词管理系统

一款简洁高效的音视频媒体管理工具，帮助您整理、分类和快速查找音视频文件，支持图片、视频、音频及文档提示词管理。

***

## 📖 软件简介

音视频管理系统是一款基于 PyQt6 开发的桌面应用程序，旨在为用户提供便捷的媒体文件管理体验。该系统支持多种媒体格式，具备强大的搜索和标签筛选功能，同时集成了提示词管理功能，方便 AI 创作工作流。

***

## ✨ 功能特点

### 🏠 首页功能

- **智能搜索**：支持按标题、提示词或标签关键词快速搜索媒体内容
- **标签筛选**：点击标签进行快速筛选，支持展开查看全部标签
- **布局切换**：支持 1x1、1x2、1x3 三种布局模式，适应不同屏幕尺寸
- **卡片预览**：图片直接显示缩略图，视频显示首帧，音频显示图标
- **修改模式**：一键进入修改模式，直接编辑标题和提示词
- **删除模式**：批量删除媒体内容，支持删除确认提示

### ➕ 添加功能

- **文件上传**：支持拖拽文件或点击按钮选择，操作便捷
- **标题输入**：为媒体内容设置简洁明了的标题
- **提示词管理**：
  - 文字模式：直接输入提示词内容
  - 文件模式：上传 Word、Excel、TXT 文件作为提示词
- **标签管理**：多个标签用逗号分隔（支持中英文逗号）
- **自动标签**：根据文件类型自动添加"图片"、"视频"、"音频"等标签

### ⚙️ 设置功能

- **文件同步**：
  - 全文件同步：复制文件到软件文件夹，支持双击打开
  - 仅同步首帧：只同步图片和视频封面，节省存储空间
  - 不同步：保持源路径，依赖原文件位置
- **默认标签**：开启后自动为媒体添加类型标签
- **删除确认**：可设置删除时是否弹出确认框
- **提示词字号**：自定义提示词显示字号
- **数据管理**：支持导出/导入数据、清空所有数据

### 🎯 快捷操作

- **双击卡片**：使用系统默认播放器打开文件
- **右键菜单**：快速修改或删除媒体内容
- **标签筛选**：点击标签按钮快速筛选同类内容

## 📁 支持格式

| 类型 | 支持格式                                            |
| -- | ----------------------------------------------- |
| 视频 | MP4, AVI, MKV                                   |
| 音频 | MP3, WAV, FLAC                                  |
| 图片 | JPG, JPEG, PNG, GIF, BMP                        |
| 文档 | Word (.doc/.docx), Excel (.xls/.xlsx), CSV, TXT |

## 📁 项目结构

```
音视频管理系统/
├── src/                     # 源代码目录
│   ├── __init__.py          # 模块初始化
│   └── main_window.py       # 主窗口组件
├── media_files/             # 媒体文件存储目录
├── cache/                   # 缓存目录（缩略图等）
├── document_files/          # 文档资源目录
│   ├── audio.png            # 音频图标
│   ├── excel.png            # Excel图标
│   ├── favicon.ico          # 软件图标
│   ├── txt.png              # TXT图标
│   └── word.png             # Word图标
├── config.json              # 用户配置文件
├── media_data.json          # 媒体数据文件
├── main.py                  # 主程序入口
└── README.md                # 项目说明文档
```

## 💡 使用技巧

1. **批量管理**：使用修改模式可以批量编辑多个媒体的标题和提示词
2. **标签分类**：合理使用标签可以快速筛选和管理大量媒体文件
3. **同步策略**：根据需求选择合适的文件同步模式，平衡性能和稳定性
4. **数据备份**：定期导出数据，防止数据丢失
